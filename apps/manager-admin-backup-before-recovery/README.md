# 🌿 Microcosm Sustainability Dashboard

> A modern and interactive sustainability dashboard UI designed to visualize environmental metrics through an intuitive and immersive user experience.

## 📖 Overview

Microcosm is a front-end dashboard concept focused on presenting sustainability and carbon impact metrics in a clean, visually engaging interface. This repository showcases the **UI/UX design only** and does not include backend services or data processing.

## ✨ Features

- Modern sustainability-focused UI
- Interactive KPI cards
- Animated backgrounds and visual effects
- Responsive design
- Light/Dark mode support
- Clean and minimal dashboard layout

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript
- MP4 Video Backgrounds
